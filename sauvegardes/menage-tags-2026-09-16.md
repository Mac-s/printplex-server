# PrintPlex — proposition de grand ménage des tags

*Analyse du 16/09/2026 sur 277 projets. Rien n'est encore appliqué : ce document liste tout ce qui changerait si tous les groupes sont validés.*

## Les groupes de changements

| Groupe | Ce que ça fait | Projets |
|---|---|---|
| **1. Cohérence univers & personnages** | Ajoute les tags « parents » manquants (Pokémon → Nintendo + Jeu vidéo + Anime ; Mario → Nintendo + Jeu vidéo ; Marvel/DC → Comics ; héros → Super-héros, méchants → Villains mais jamais les deux ; Power Rangers → Sentai + TV Show ; Star Wars → Movie). Ajoute les personnages manquants (Doctor Doom, Samus Aran, Roronoa Zoro, Rogue, Sally, Gengar, Jean Grey, Link…). Anime → Animation pour les dessins animés occidentaux (X-Men 97, Invincible, What If, TMNT). Corrige les « Props » mal placés (casques, présentoirs → nouveau tag Présentoir), ajoute Bouclier, retire Bruce Wayne / Character / 2077 / Microsoft, corrige Epée → Épée, Jack → Jack Skellington, Masterchief → Master Chief, « Saut à Popcorn » → « Seau à popcorn ». Tague complètement Link's Hylian Shield (aucun tag ni catégorie aujourd'hui). | 110 |
| **2. Multi-couleur** | Ajoute « Multi-couleur » aux projets qui ont des fichiers COLOR/Colored/AMS mais pas le tag. | 100 |
| **3. Fusion des tags génériques** | Décoration intérieure → Décoration ; Botanique + Floral → Plantes ; Rangement → Support / Organiseur ; Lampe → Éclairage ; retire « Accessoire » (trop vague) ; retire « Maison » des jeux PlayBook'd ; retire « Décoration » là où la catégorie est déjà décorative (Poster 3D, 3D Cards, Figurines, Life Size, Accessoire Écran). | 68 |
| **4. Tags génériques en français** | Movie → Film, TV Show → Série TV, Villains → Méchants, Food → Nourriture, Cards → Cartes, Keyboard caps → Touches de clavier, Scepter/Staff → Bâton / Sceptre, Dino → Dinosaure, Snake → Serpent, Chess → Échecs, Sea Battle → Bataille navale, Tic Tac Toe → Morpion… Les noms propres (Marvel, Batman, Pikachu…) ne changent pas. Supprime aussi les doublons anglais/français (Hangman + Pendu → Pendu). | 74 |
| **5. Sentai → Tokusatsu** | « Sentai » est faux pour Beetleborgs et Kamen Rider ; « Tokusatsu » couvre les trois. | 11 |
| **6. Catégories** | Porte Serviettes → Salle de bain ; Solace Napkin Holder → Cuisine ; Pumpkin Pikachu and Gengar → Figurine Life Size (comme Pumpkin Charmander) ; Orso Glasses Hanger → Maison (comme Laro et Verdin) ; Horloge (Le Front Fuyant) → Décoration (comme Grove Clock) ; Porte-manteaux Pinceaux → Maison ; Link's Hylian Shield → Cosplay. | 7 |
| **7. Tags uniques qui répètent le nom** | Retire les tags utilisés par un seul projet et déjà contenus dans son nom, hors univers et personnages (Cornhole, Backgammon, Mancala, Burger, Sushi, Monstera, Mahjong…). Allège la liste de filtres sans rien perdre à la recherche (elle cherche aussi dans le nom). | 19 |

**Tout cumulé :** 230 projets modifiés, 259 → 234 tags distincts, 134 → 109 tags utilisés une seule fois.
